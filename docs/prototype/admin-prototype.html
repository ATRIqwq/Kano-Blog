分布式Session登录技术

📌 本篇文章是分布式登录技术笔记，涵盖 Session 共享的三种主流方案

一、问题背景

在集群部署下，用户登录状态存放在单台服务器的 Session 中，请求被负载均衡到其他节点时无法识别，导致反复登录。

二、解决方案对比

① Session 复制：Tomcat 自带集群 Session 复制，配置简单但只适合小规模集群。

② Redis 共享（推荐）：将 Session 存入 Redis，所有节点共享。

③ Token 无状态：JWT 等无状态方案，服务端不保存状态，扩展性最好。
